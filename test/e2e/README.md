# 프론트 브라우저 테스트

- 확장과 PWA를 실제 브라우저(Chromium)로 띄우고, 가짜 분석 서버로 여러 상황을 확인한다
- 실제 AI 서버와 백엔드는 필요 없다 (8080, 8000 포트가 비어 있어야 함)

## 처음 한 번

```
npm i -D playwright
npx playwright install chromium
```

## 실행

```
npm run test:e2e          # 전체
npm run test:e2e -- ext   # 확장만
npm run test:e2e -- pwa   # PWA만
```

- 마지막 줄이 `# N/N 통과`(앞뒤 숫자가 같음)면 정상
- 빌드 결과와 테스트 사진은 `test/e2e/out`에 만들어지고 git에는 올라가지 않는다

## 확인하는 것

- 확장
  - 검사 버튼 붙는 사진, 조작 의심 배지와 결과창(확률, 판정 이유, 얼굴, 히트맵 탭)
  - 같은 사진 재검사 안 함, 버튼 연타해도 요청 1번
  - AI 모델 미로드, 빈 결과, 확률이 문자인 결과, 판정 값이 문자열인 결과
  - 경계값(49.9%, 79%), HTML 공격 문구, 이상한 얼굴 위치, 깨진 히트맵, 범위를 벗어난 확률
  - 클린 모드, 검사 중 전원 끄기와 다시 켜기
  - 캐시 비우기(다른 탭 정리, 통계 유지, 서버 재시작 뒤)
  - 얼굴은 찾았지만 사진 전체로 판정한 응답 (모두 화질 낮음, 그 밖의 이유)
  - 끌어다 놓기 모달 (결과창이 모달에 가려지지 않음, 닫으면 같은 주소의 페이지 사진에 결과 표시, 파일 놓기, 화면 가운데의 큰 사진 위에 모달이 떠도 그 사진의 버튼과 배지가 사라지지 않음)
  - 겹친 사진, 팝업 서버 상태
  - 사진 400장 페이지 멈춤, 계속 바뀌는 페이지의 새 사진
- PWA
  - 결과와 히트맵 안내, 500, 429, HTML 응답, 빈 결과, AI 모델 미로드
  - 경계값, 공격 문구, 이상한 응답, 깨진 사진, PDF, 큰 사진
  - 영상 고르기 (1초 장면, 장면 이동, 끝 지점 보정, video_frame 전송, 열 수 없는 영상)
  - 너무 작은 사진과 영상 (짧은 변 79px 거절, 80px 통과, 거절할 때 서버에 보내지 않음)
  - 얼굴은 찾았지만 사진 전체로 판정한 응답
  - 서버 재시작 뒤 기록 지우기, 서버 상태 표시
