# VeritAI 프론트엔드 개선 (2026-11-11)

## 새 기능

- PWA 영상 선택: 갤러리에서 영상을 고르면 브라우저에서 장면 한 장만 사진으로 뽑아 검사 (영상은 서버로 보내지 않음, `mediaType: video_frame`)
  - 1초 지점을 먼저 보여 주고 슬라이더와 -5초, -1초, +1초, +5초 버튼으로 장면 이동
  - 열 수 없는 영상은 안내 문구
- 앱 영상 시간 막대: 막대를 끌거나 눌러서 장면 이동 (새 네이티브 모듈 없이 `PanResponder`)
  - 공유받은 영상도 길이를 읽어 막대와 구간 버튼(처음, 1/4, 절반, 3/4)이 나옴
- 작은 사진 거절: 짧은 변이 80px 미만인 사진과 영상 화면은 PWA와 앱에서 서버로 보내기 전에 거절 (확장은 기존처럼 화면에서 80x80 미만을 건너뜀)

## 표시 개선

- 얼굴별 확률, 판정 이유 문장, 사진 위 배지를 소수 첫째 자리까지 표시 (기준값 80%와 인식 신뢰도는 정수)
- 히트맵 안내 문구: 확률 1% 미만이어도 색은 그대로 칠하고, 문구를 "조작 가능성이 매우 낮다, 색은 조작 흔적이 아니라 정상이라고 판단할 때 AI가 많이 본 곳"으로 변경
- 얼굴을 찾았지만 전체 이미지로 판정한 경우의 문구를 이유별로 구분
  - 찾은 얼굴이 모두 화질 낮음: "얼굴 N개를 찾았지만 모두 화질이 낮아 사진 전체로 검사"와 다시 검사 안내
  - 그 밖의 이유: "분석에 쓰지 못해 사진 전체로 검사"
  - 서버가 화질 낮은 얼굴을 분석에서 빼는 규칙(`ai/cnn.py`)에 맞춤

## 끌어다 놓기(드랍존) 수정

- 결과창이 모달 뒤에 가려지던 문제 수정 (결과창 상자를 문서 맨 뒤로 이동)
- 모달을 닫으면 같은 주소의 페이지 사진에 결과 배지 표시 (서버 요청 없이 캐시 사용)
- 모달 사진이 아래 페이지 사진의 버튼과 배지를 영구히 숨기던 문제 수정 (모달 사진을 겹침 규칙에서 제외)
- 모달 안을 클릭한 뒤 Esc가 안 먹던 문제 수정. 어두운 배경 클릭으로도 닫힘. 글을 쓰는 중에는 Esc로 닫히지 않음
- 연달아 놓으면 모달이 겹치지 않고 새 사진으로 교체
- 모달이 열린 동안 뒤 페이지가 스크롤되며 결과창이 닫히던 문제 수정 (Ctrl+휠 확대는 유지)
- 깨진 파일, 막힌 주소, 사진이 아닌 링크, PDF, 여러 파일을 놓았을 때 안내 문구
- 모달을 닫은 직후 닫힌 사진을 검사하려던 문제 수정
