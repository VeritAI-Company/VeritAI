# VeritAI 프론트엔드 개선 (2026-11-09)


## 안정성

- 결과 조회 중 연결이 끊겨도 3번까지 다시 시도 (확장, PWA, 앱)
- 서버 응답을 읽지 못해 3분 동안 "분석 중"에 멈추던 문제 수정
- 사진 가져오기에서 오류 페이지와 15MB 넘는 파일을 거름
- 파일 끌어다 놓기 검사가 실패하던 문제 수정
- 동시에 끝난 검사의 오늘 통계가 빠지던 문제 수정
- 앱 리포트 화면이 결과를 못 받으면 10초 뒤 안내

## 보안

- 확장 결과창을 Shadow DOM으로 옮겨 사이트 CSS와 분리
- 끌어온 HTML에서는 사진 주소만 꺼냄

## 판정 일관성

- 사진 압축 기준을 세 채널 모두 1280px, JPEG 0.92로 통일 (이전에는 채널마다 달랐음)
- 확률은 버림으로 표시 (49.96%가 "50.0%, 정상"으로 보이던 모순 해결)
- AI 결과 형식이 이상하면 "정상 0%" 대신 오류로 표시

## 사용 편의

- 신고 입력에서 한글 Enter 시 마지막 글자가 빠지던 문제 수정
- 오른쪽 아래 안내가 사이트 버튼을 가리지 않음
- 작은 사진의 오류 문구는 줄이고, 마우스를 올리면 전체 문구 표시
- 끌어다 놓기 모달 Esc 닫기, 결과창 터치 드래그, 입력 중 단축키 무시
